# My Dialer

برنامه تماس ساده برای اندروید ۶ (API 23) با قابلیت بلاک شماره در صفحه تماس ورودی.

## امکانات
- صفحه شماره‌گیری با دکمه‌های اندازه‌پذیر (sp) که با بزرگ‌شدن فونت از صفحه خارج نمی‌شوند
- نمایش تماس ورودی روی صفحه قفل
- دکمه **رد و بلاک** برای تماس‌های ورودی
- ذخیره شماره‌های بلاک‌شده به‌صورت محلی (SharedPreferences)
- تماس‌ها بدون نیاز به اینترنت؛ برنامه هیچ دسترسی اینترنت ندارد

## نیازمندی‌ها
- Android Studio (Hedgehog یا جدیدتر)
- JDK 17 یا بالاتر (برای Gradle)

## ساخت و نصب
1. مخزن را کلون کنید: `git clone https://github.com/<username>/MyDialer.git`
2. پروژه را در Android Studio باز کنید. اگر پیام ساخت Gradle Wrapper آمد، آن را بپذیرید.
3. APK را بسازید: **Build > Build Bundle(s) / APK(s) > Build APK(s)**
4. روی گوشی نصب کنید (باید «نصب از منابع ناشناس» فعال باشد).
5. در برنامه، دکمه **تنظیم به‌عنوان تماس‌گیرنده پیش‌فرض** را بزنید.

## محدودیت‌ها
- بلاک فقط وقتی کار می‌کند که برنامه تماس‌گیرنده پیش‌فرض باشد.
- شماره‌ها دقیقاً مطابقت داده می‌شوند؛ شماره با و بدون کد کشور جداگانه بلاک می‌شود.
- لیست مخاطبین و تاریخچه تماس هنوز پیاده‌سازی نشده است.

## مجوزها
- `CALL_PHONE`: برقراری تماس از صفحه شماره‌گیری
- `BIND_INCALL_SERVICE` (سیستمی): نمایش و کنترل تماس‌های ورودی و خروجی
